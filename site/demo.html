Drag and drop a notebook, Python file, small repo snapshot, or public GitHub repo URL here

Choose local files/folders, or fetch bounded public GitHub files client-side. No backend, no token, no paid API.

Folder mode: choose your repo root when the browser asks for a directory. Selected local files stay in this browser tab and are not uploaded to a labcheck backend. Browser folder selection works best in Chrome or Edge; if your browser blocks folder picking, use Choose files for a small snapshot or run the CLI for a complete local scan.

Public GitHub URL audits are bounded to 80 prioritized text-like files, 750 KB each: README/manifests, runtime files, CI, Docker/Make files, notebooks, and Python source first. Share `demo.html?repo=owner/repo` to prefill a public repo, or use the CLI for full-repo scans.

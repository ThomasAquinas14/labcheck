Drop a notebook or small repo snapshot. Get instant reproducibility triage.

This demo runs entirely in your browser. It does not upload your files anywhere, and it does not use any API keys.

It focuses on a high-signal subset of `labcheck`: notebook hidden state, saved notebook errors, dependency manifests, missing local inputs, README drift, machine-local paths, randomness without visible seeding, sklearn/pandas random_state gaps, and simple read/write lineage.
